# Atribuciones

`uniform_baseline` y la fórmula salarial proceden de [ai-05-ide/sim.py](https://github.com/sbvasquezg-ux/ai-05-ide/blob/main/sim.py) y `extensions.md`, sección 4. Se renombra el corte ocupacional como `cutoff` para no confundirlo con el costo de validación.

`slides/vh-beamer.sty` adapta `assets/ide-beamer.sty` del mismo repositorio: prefijo IT → VH y URL del proyecto. Se conserva la paleta.
